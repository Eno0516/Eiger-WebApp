# 画面構成

# ユーザー側
* PC・スマホ両方で使用しやすいようにする必要がある

## ホーム画面
* path: "/"
* LINE 認証必須（未認証は LINE ログイン画面へリダイレクト）
* 個人情報未登録でも閲覧可能
* 詳細設計: `features/feature/login.md`

## 初期登録画面
* path: "/sign_up"
* LINE 認証必須（未認証は LINE ログイン画面へリダイレクト）
* 個人情報未登録でもアクセス可能
* 外部 LIFF フォームへのリンクを表示し、初回登録を案内する
* クエリパラメータ: `redirect_url`（登録完了後の遷移先。省略時は `/`）
* フォーム完了検知: タブを閉じた後の `window.focus` イベントでバックエンドへ状態確認
* 詳細設計: `features/feature/sign_up.md`

# 注：以下全ての画面は LINE 認証チェックが必要
## ユーザーホーム画面
* path: "/user_home/{app_UUID}"
* 各サークルの専用ページに飛べる画面

# 注：以下全てのページは各サークルに紐付く権限によって表示が異なる
## サークル画面
* path: "/club_pages/{サークルのUUID}"
* サークル専用のページ
* 公開範囲権限により、admin,member,visitorで見れる情報が異なる
* そのサークルへの参加要望などもこのページで行う
* memberに昇格された場合には、サークル内部の各データが確認できる

## サークル管理ページ
* この際、各サークルのスプレッドシートに保管された内部データは確認できない
* サークルの作成・削除のみを行う
* ユーザー管理はサークルのadminユーザーに委譲し、こちらでは行わない
* 広告対応を考え、アプリ内に保存された個人情報ではない属性などは確認できることとする
