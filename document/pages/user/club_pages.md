# サークル画面 設計メモ

## 基本方針

- 管理者・一般ユーザーでページを分けない
- 権限（`admin` / `member` / `visitor`）によって表示を切り替える

## 権限ごとの表示

| 権限 | 見れる内容 |
|------|-----------|
| visitor | サークル概要・参加申請 |
| member | サークル内部データ |
| admin | member の内容 + 管理機能（設定・メンバー管理など） |

## サークル参加申請フロー

1. `/club_page/{サークルUUID}` から参加申請ボタンを押す
2. フォームビルダーで作成したフォームを LIFF で開く（Google Forms 不要）
3. LIFF SDK により app UUID が自動識別される（手動入力・URL 埋め込み不要）
4. 回答は DB に保存、admin が閲覧・Circle Sheet にエクスポート可能

## 属性情報（大学・学部・学年など）の収集

- 大学・学部・学年はアプリ DB（`user_profiles`）に保持
- サークルごとに追加で必要な項目はフォームビルダーで収集・DB に保存

## 会計管理

- 要件未確定のため保留
- 実装時は `admin` 権限のみ表示するセクション or タブとして追加予定
