# 広告機能 設計メモ

## 自前DBに持つユーザー属性

| カラム | 理由 |
|--------|------|
| `university` | 地域・偏差値層での出し分け |
| `faculty` | 理系/文系・特定学部向けの出し分け |
| `grade` | 学年による出し分け（就活向けなど） |
| `nickname` | 表示用（バックエンドでのターゲティングには使用しない） |

## 収集しないもの

- **学科**：学科単位で絞った広告ニーズがほぼないため省略
- **メール**：個人情報保護の観点から収集しない

## 収集方法

- 大学・学部・学年は初期登録時にアプリ内フォームで収集し `user_profiles` に保存
- LIFF SDK により app UUID が自動識別されるため、URL 埋め込みや手動入力は不要

## 表示ルール

- UI 上はニックネームのみ表示
- 大学・学部・学年はバックエンドでの広告ターゲティング処理にのみ使用し、外部に公開しない

## ニックネームのガイドライン

- **姓名フルネーム禁止**（例：田中太郎）
- 下の名前やあだ名は許可
- プライバシーポリシーおよび利用規約に明記する
