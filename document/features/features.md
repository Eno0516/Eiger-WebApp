# 実装予定の機能
* 上から順に実装予定
* 個人情報をアプリ内に保持しないこと

## ログイン機能
* LINE Login（LIFF）による認証を採用
    * OAuth 2.0 + OpenID Connect ベースで Google Login と同等のセキュリティ
    * 部員は全員 LINE を持っている前提のため、追加アカウント不要でログイン可能
* 各自任意で設定できる、アプリ内での表示名はフルネームなど個人を特定できるものはNGとし、部内でのあだ名を用いること
* ログイン時には以下の3つの状態を取る
    * Admin: 管理者
        * 幹部などがこれにあたる想定。他のメンバーの権限付与・フォーム作成など全機能を使用可能
    * Member: サークルメンバー
        * サークルのメンバー。一部情報の閲覧、フォームへの回答、投票機能への投票などが可能
    * Visitor: 参加希望者
        * Admin に参加をまだ認められていない状態。サークルの概要や新歓予定などは確認可能だが、内部の詳細データなどはアクセス不可

## 初期登録機能
* LINE Login 完了後、初回ユーザーを LIFF フォームへ誘導して登録を行わせる
* display_name・大学・学部・学年はバックエンド DB に保存、本名は GAS 経由で Global Sheet のみに保存
* フォーム送信後、タブを閉じると元のページが `window.focus` イベントで完了を検知
* 登録完了後は指定された `redirect_url` または `/` へ遷移する
* **初期登録フォーム自体もフォームビルダー機能で作成する**（フォームビルダー実装後に移行予定）
### 詳細設計
* [設計 初期登録機能](feature/sign_up.md) を参照

## サークル機能
* サークルの作成・参加申請・承認・メンバー管理を行う
* system_admin がサークルを作成し、ユーザーが参加申請 → circle_admin が承認する流れ
* 実装順:
    1. サークル作成（system_admin）
    2. サークル一覧・詳細表示
    3. 参加申請・承認フロー
    4. メンバーロール管理
### 詳細設計
* 設計ドキュメント未作成

## フォームビルダー機能
* サークル admin がアプリ内でフォームを作成・管理できる
* メンバーは LIFF 上で回答し、LINE 認証により app UUID が自動識別される（手動入力不要）
* フィールドタイプ: テキスト入力 / 単一選択 / 複数選択
* 回答はアプリ DB に保存し、必要に応じて GAS 経由で Circle Sheet にエクスポートする
* 回答閲覧は circle_admin のみ
* **初期登録フォームもこの機能で作成・運用する**
### 詳細設計
* [設計 フォームビルダー機能](feature/form_builder.md) を参照

## メンバー管理機能
* フォームビルダー機能により、circle admin が任意の情報を収集する
* 回答は DB に保存され、circle_admin のみ閲覧可能

## LINE アカウント 連携機能
* 後述の機能のために、各メンバーのLINE アカウントを連携しておく。
* メンバーは公式LINEを追加することで完了
* 公式LINEを使用
    * 月1000件を超えると課金のため注意だが、問題ない？

## 活動内容ページ
* 1活動に1つ専用のページを作成すること
* 作成・編集はadminのみ
* ページには任意に活動内容の詳細を書いて良いが、個人情報は記載しないこと
* 以下の情報は入れ込むことを推奨するため、入力欄を設ける
    * 参加申請フォーム（フォームビルダーで作成したフォームをアプリ内で紐付ける・Google Forms 不要）
    * LINE グループ招待リンク
        * LINEグループは作成段階で「招待リンク」を作成できる。これを登録しておけばアプリ内で公式LINEから自動で参加確定メンバーに招待リンクを送ることが可能。

## サークル予定表
* カレンダー形式でサークルの予定を表示する。
* 活動内容ページを紐付けること

## 集計機能
* Adminユーザーが任意の内容で集計を作成できる機能
    * 例
        * 奢り金額
        * ランキング
        * 総走行距離

## 表集計機能
* Adminユーザーが任意の内容で表形式の集計を作成できる機能
    * 例
        * 怪我の部位制覇
        * 都道府県制覇

## 部内フリマ機能
* 権限: Member以上が使用可能
* 出品者は写真と詳細情報を載せて掲示板のような形式で不要物品を掲示できる。
* 欲しいメンバーがいた場合は、「欲しいボタン」を押して意思を示す
    * 金銭の受け取りと個人情報の提供はアプリ内で行わず、「欲しいボタン」の押下と共に、受け渡し用のLINEグループへの招待リンクを提供する
    * または、出品者に公式LINEから誰々が希望しています等と通知が飛ぶようにするか
    * 出品者は受け渡すメンバーの決定後、速やかに掲示を削除すること

## 活動ごとの送迎位置表示機能
* 活動で車での送迎が必要な場合、それらの位置情報をGoogle Mapで一覧にし表示する
    * Google Maps API は有料なので広告付いたら実装
